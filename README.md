# hxwl-11 儿童散瞳排程台

滴药登记、危险病例拦截、药效窗口排程与检查补录的本机工作台。

## 技术栈

React + Vite + TypeScript + CSS，数据保存在浏览器 localStorage。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111。`npm run typecheck` 可做静态类型检查。

## 业务规则

- 登记字段：患者、眼别（右/左/双眼）、药品批次、滴眼时刻、散瞳前眼压。
- 危险判定（`src/rules`，阈值集中在 `constants.ts`）：
  - 眼压 ≥ 21 mmHg：禁止散瞳；
  - 药品批次过期（到期当日仍有效）：禁止使用；
  - 距该患者上一次有效滴药不足 5 分钟：拦截。
- 危险病例**保留登记输入并列出原因、建档留痕**，不进入排程、不释放仪器。
- 检查只能排在药效窗口内（滴药后 20 分钟起效；窗口时长取药品批次配置）。
- 仪器按 15 分钟时段排班，**同一仪器同一时段只留一人**（reducer 内另有一道冲突复核）。
- 检查后补录双眼瞳孔直径与散瞳验光值，档案标记为已检查。
- 补滴：作废原档案与原排程（仪器时段立即释放），按新滴药时刻重新计算窗口并生成新时段；补滴登记同样经过危险判定。

## 目录分层

- `src/archive/`：档案层——数据类型、批次/仪器配置、示例档案、reducer、时间格式工具。
- `src/rules/`：判定层——危险判定、药效窗口、时段网格、仪器冲突，全部为纯函数。
- `src/storage/`：本机留档层——localStorage 读写，不含业务逻辑。
- `src/ui/` 与 `src/App.tsx`：界面层——表单、危险面板、候诊队列、排程看板、弹窗、留档列表。
